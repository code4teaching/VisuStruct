# VisuStruct 1.2.4

Patch release **after** **1.2.3**.

## Fixes

- **Code generator:** **Generate** did nothing after the Kotlin port because `JNumberField.isNumeric()` compiled an invalid regex (`PatternSyntaxException`). Indent fields now parse numbers with `toDoubleOrNull()`.
- **Element editor:** **Apply text** crashed on `Regex.split(…, -1)` (Java’s “keep empties” limit is not valid in Kotlin).
- **Hints:** editor example strings showed long backslash runs after i18n sync doubled `.properties` escapes. Sync/resync now unescape before rewriting.
- **Palette → Generate code** applies pending editor text first (same as **File → Generate code**).

## UI

- **Code generator** dialog is **resizable**; the old fixed 498×458 absolute layout no longer clips buttons on HiDPI or with long translations.
- **Output** hint includes a concatenation example (`output: "Ergebnis: " + ergebnis` / `output: "Result: " + result`).

## Internationalization

- Further **Swift** string sync for editor/dialog keys; `tools/java_swift_i18n_map.json` is kept in this repo as a fallback map.

## Tests

- `CodeGenRulesJavaTest`: Java input/output lines and numeric indent fields.

## Build

- Maven: **`de.visustruct:visustruct:1.2.4`**
- Fat JAR: **`visustruct-1.2.4.jar`** (`./mvnw package` → `target/`)
- Release also ships **`visustruct.jar`**.
